# 复现材料（Issue #1）

## 背景

v0 直答版：用户问题直接进 prompt → LLM 自由生成推荐。`data/shops.json` 已备好 30 家种子店，但直答版完全不读库。

## 复现步骤

```bash
python3 repro/naive_direct_answer.py
```

无任何外部依赖。预期输出（每次不同）：

```
问：台东有什么宝藏苍蝇馆子
答：你问「台东有什么宝藏苍蝇馆子」，这几家绝对不踩雷：
- 老台东十六号院海鲜居（市北区台东六路 16 号）：招牌 辣炒蛤蜊、原汁海虹，评分 4.9，本地人强烈推荐。
...
```

## 故障判定（机械化）

- 输出中的店名与 `data/shops.json` 的 `name` 字段求交集：**交集 = ∅**（0% 命中）；
- 输出包含具体地址、评分、招牌菜：**格式完全可信的编造**；
- 不同 seed 输出不同：**不可回归**。

## 根因

架构性：LLM 同时掌握「事实生成权」与「语言组织权」。语料里没有本地小店数据时，模型按"美食推荐的语言分布"补全——每一段都流畅，每一个实体都是假的。

## 修复

PR #2：接地管线（结构化候选集 + LLM 仅包装 + 回校器 + 拒答层）。修复后同一问题的输出 100% 锚定库内数据，机械判据见 `tests/test_regression.py`。
